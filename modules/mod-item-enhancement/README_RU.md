# Улучшение предметов для AzerothCore 3.3.5a

Комплект предназначен для ядра `yakanikel-droid/541ac`. Он содержит серверный модуль, SQL, конфиг и встроенное
клиентское окно FrameXML. Это не аддон: окно загружается самим интерфейсом клиента из MPQ-патча.

## Возможности

- NPC `Кузнец драконьей ковки <Мастер улучшения снаряжения>`.
- Вкладки `Заточка` и `Перенос`.
- Цена заточки зависит от ItemLevel и целевого уровня.
- Отдельные шанс и итоговый процент характеристик для каждого уровня.
- Белый список усиливаемых ItemModType.
- Белый список SpellID: у них масштабируется только BasePoints предметного заклинания.
- Обычная неудача сбрасывает предмет до +0.
- Камень защиты заменяет полный сброс потерей одного уровня.
- Камни шанса на +7% и +10%.
- Три серии гарантированных сфер I–X: ItemLevel до 100, до 200 и без ограничения.
- Запрет наследуемых предметов, чёрный и белый списки ItemEntry.
- Перенос снимает заточку с исходного предмета и ставит её на незаточенный целевой предмет.

## Сервер

1. Скопируйте каталог `mod-item-enhancement` в `azerothcore-wotlk/modules/`.
2. Из корня AzerothCore примените обязательную защиту служебного слота:

   `git apply modules/mod-item-enhancement/patches/required_item_socket_guard.patch`

   Она не даёт ядру ошибочно считать метку заточки дополнительным сокетом.
3. Скопируйте `conf/mod_item_enhancement.conf.dist` в каталог конфигурации сервера либо позвольте установке модуля
   установить dist-файл штатно.
4. Повторно запустите CMake и соберите ядро.
5. SQL из `data/sql/db-world/base/` устанавливается штатным загрузчиком SQL модулей. При ручной установке выполните
   `item_enhancement_world.sql` в world-базе.
6. Добавьте spawn NPC 900000 в таблицу `creature` на выбранных координатах. В SQL оставлен шаблон.

Уровень хранится в `PRISMATIC_ENCHANTMENT_SLOT` как EnchantID `50000 + уровень`. Предмет с уже занятым дополнительным
сокетом модуль не принимает, поэтому существующая кузнечная механика не уничтожается.

## Клиент

1. Извлеките клиентский `Interface/FrameXML/FrameXML.toc` в рабочую папку MPQ.
2. Добавьте в конец `FrameXML.toc` строку:

   `ItemEnhancementFrame.xml`

3. Скопируйте из комплекта оба файла:

   - `client/Interface/FrameXML/ItemEnhancementFrame.xml`
   - `client/Interface/FrameXML/ItemEnhancementFrame.lua`

   в `Interface/FrameXML/` клиентского MPQ-патча.
4. Извлеките оригинальный `DBFilesClient/SpellItemEnchantment.dbc` клиента и выполните:

   `python tools/patch_enchantment_dbc.py SpellItemEnchantment.dbc SpellItemEnchantment_patched.dbc`

5. Положите полученный файл в клиентский MPQ как `DBFilesClient/SpellItemEnchantment.dbc`.
6. Тот же полученный DBC скопируйте на сервер в `Data/dbc/SpellItemEnchantment.dbc`.

Записи 50001–50010 не дают характеристик сами. Они являются видимой меткой `Улучшение +N`; реальные бонусы считает
сервер. Встроенный FrameXML находит эту метку в подсказке и добавляет `+N` к имени предмета. Поэтому заточку видно
владельцу, в ссылках и при осмотре другим игроком, если у него установлен этот клиентский патч.

## Перенос

Настройки:

```ini
ItemEnhancement.Transfer.Enable = 1
ItemEnhancement.Transfer.MaterialItemId = 70096
ItemEnhancement.Transfer.MaterialCount = 1
```

Правила:

- исходный и целевой предметы должны быть разными;
- исходный должен иметь заточку;
- целевой должен быть без заточки;
- оба предмета должны проходить общие ограничения;
- после операции исходный становится +0, целевой получает прежний уровень;
- затем сервер списывает настроенное количество ресурса.

## Имена разрешённых характеристик

`STRENGTH`, `AGILITY`, `STAMINA`, `INTELLECT`, `SPIRIT`, `ATTACK_POWER`, `RANGED_ATTACK_POWER`, `SPELL_POWER`,
`HIT_RATING`, `CRIT_RATING`, `HASTE_RATING`, `EXPERTISE_RATING`, `ARMOR_PENETRATION_RATING`, `DEFENSE_RATING`,
`DODGE_RATING`, `PARRY_RATING`, `BLOCK_RATING`, `RESILIENCE_RATING`, `BLOCK_VALUE`, `SPELL_PENETRATION`,
`MANA_REGEN`, `HEALTH_REGEN`.

## Важные правила безопасности

- Клиент передаёт только расположение выбранных предметов. Право собственности, дистанцию до NPC, цену, шанс,
  материалы и результат всегда проверяет сервер.
- Особый материал один и необязательный. Сфера, камень шанса и защита не комбинируются.
- Сфера расходуется только при гарантированном успешном применении.
- Камень шанса расходуется при попытке.
- Защита по умолчанию расходуется только при неудаче.
