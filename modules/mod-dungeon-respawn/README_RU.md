# Dungeon Respawn для 541ac

Исправленная версия модуля AnchyDev/DungeonRespawn для ветки
`yakanikel-droid/541ac` (AzerothCore, C++20).

## Установка

1. Скопировать папку `mod-dungeon-respawn-541ac` в `modules/`.
2. Перезапустить CMake и пересобрать worldserver.
3. В `dungeonrespawn.conf` установить `DungeonRespawn.Enable = 1`.

Таблица `dungeonrespawn_playerinfo` устанавливается системой обновлений модулей.

## Исправления

- Обновлены имена PlayerScript-хуков под API ветки 541ac.
- Исправлено небезопасное удаление игрока из списка при выходе.
- Убраны глобальные определения из заголовка и рекурсивный поиск состояния.
- Исправлена схема таблицы: `guid` является обычным первичным ключом, а не AUTO_INCREMENT.
- Добавлены защита от повторного добавления GUID и проверка сохранённой карты.
- Значение здоровья ограничивается диапазоном 0-100%.
- Состояние корректно перечитывается после `.reload config`.

Полная сборка ядра в архив не входит.
