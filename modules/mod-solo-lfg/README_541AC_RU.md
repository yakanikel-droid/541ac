# mod-solo-lfg для ядра 541ac

## Исправление роли UNKNOWN

Модуль не изменяет стандартные клиентские файлы FrameXML. Перед постановкой в
очередь сервер проверяет, что игрок выбрал ровно одну боевую роль: танк,
лекарь или боец. Запрос с нулевой или комбинированной ролью отклоняется до
создания предложения. В Solo LFG стандартная проверка состава из пяти игроков
обходится, поэтому именно модуль обязан выполнить эту проверку самостоятельно.
Это не позволяет серверу передать роль `UNKNOWN`, из-за которой стандартный
клиент 3.3.5a выдавал ошибку в `LFGFrame.lua`.

Официальный модуль включает Solo LFG через `ToggleTesting()`. Для клиента
3.3.5a это небезопасно: Testing меняет обработку предложения, а не только
допустимое число игроков. Эта версия использует отдельный производственный
флаг Solo LFG и никогда не включает Debug/Testing.

Поэтому вместе с модулем устанавливается обязательный патч
`541ac-solo-lfg-core.patch`. Он добавляет отдельный флаг в LFGMgr и изменяет
только две проверки количества игроков в LFGQueue.

## Установка

1. Распаковать папку `mod-solo-lfg` в каталог `modules` ядра.
2. Из корня `azerothcore-wotlk` применить `541ac-solo-lfg-core.patch`.
3. Повторно выполнить CMake-конфигурацию.
4. Собрать и установить сервер.
5. Отредактировать установленный файл `SoloLfg.conf`.

Рекомендуемая конфигурация:

```ini
SoloLFG.Enable = 1
SoloLFG.Announce = 0
SoloLFG.FixedXP = 1
SoloLFG.FixedXPRate = 0.2
```

В основном `worldserver.conf` обязательно оставить:

```ini
Debug.LFG = 0
```

## Совместимость

- сигнатуры `OnPlayerRewardKillRewarder` и `OnAfterConfigLoad` совместимы с `541ac`;
- SQL-миграции не требуются;
- модуль совместим с установленным `mod-autobalance`;
- исходники проверены компилятором `g++ 13` в режиме C++20.

Модуль включает отдельный режим Solo LFG ядра 541ac через `SetSoloLfgEnabled`.
Отладочный режим LFG не включается. Перед очередью также требуется выбрать
ровно одну боевую роль.
